# はじめかた — ECHELON を動かす

このプロトタイプを画面で動かすまでの手順です。プログラミングの知識は要りません。
**Windows** を前提にしています。

---

## 1. 最初の1回だけ必要な準備

### Node.js を入れる

このプロトタイプは Node.js というソフトの上で動きます。入っているか分からない場合は、
そのまま次の手順に進んで確認できます。

1. <https://nodejs.org/> を開く
2. 大きく表示されている **LTS** と書かれたボタンからダウンロード
3. ダウンロードしたファイルを実行し、**すべて「次へ」で進めてインストール**

> すでに入っている場合は、インストーラーが「修復」などと表示します。そのまま閉じて構いません。

---

## 2. 毎回の起動手順

### ① ターミナルを開く

エクスプローラーで `ECHELON` フォルダを開き、
**アドレス欄(上のパスが出ている場所)をクリックして `powershell` と入力し、Enter**。

黒い(または青い)ウィンドウが開きます。これがターミナルです。
以降はここに文字を打ち込んで Enter を押します。

> うまくいかない場合: スタートメニューで「PowerShell」と検索して開き、
> 次の1行を打ってから Enter を押してください。
>
> ```
> cd ECHELON
> ```

### ② 部品を用意する(初回と、ファイルが更新されたときだけ)

```
npm install
```

数十秒〜数分かかります。大量の文字が流れますが、正常です。
最後に `added ... packages` のような表示が出れば完了です。

### ③ 起動する

```
npm run dev
```

数秒で、次のような表示が出ます。

```
  ➜  Local:   http://localhost:5173/
```

### ④ ブラウザで開く

表示された `http://localhost:5173/` を、ブラウザ(Chrome や Edge)のアドレス欄に
入力して開きます。**ターミナルのリンクを Ctrl キーを押しながらクリックしても開けます。**

戦闘が始まります。

### ⑤ 終わるとき

ターミナルで **Ctrl + C** を押します。「バッチ ジョブを終了しますか」と聞かれたら `Y` + Enter。

> ⚠️ ターミナルを閉じずに放置すると起動したままになります。次に `npm run dev` すると
> 「Port 5173 is in use」と出て別の番号(5174 など)で起動します。動作に支障はありませんが、
> 気になるときは一度 Ctrl + C で止めてください。

## 3. 画面の見かた

```
┌──────────────────────────────────────────────────────┐
│ 0:59 tick 1795   [⏸ 一時停止] [×1] [⏭ ステップ]       │  ← 時間の操作
│                                                       │
│ ┌──────────┐                          ┌────────────┐ │
│ │ 規模     │                          │ BLUE 86/88 │ │  ← 両軍の戦力
│ │ 視点     │        戦場               │ RED  85/87 │ │
│ │ 陣営     │                          ├────────────┤ │
│ └──────────┘                          │ 指揮階層    │ │  ← クリックで
│                                        │ 中隊長     │ │     指揮官交代
│ ┌──────────┐                          │  小隊長    │ │
│ │ 拠点     │                          │   分隊長   │ │
│ └──────────┘                          └────────────┘ │
└──────────────────────────────────────────────────────┘
```

### 左上のパネル

| 項目 | 意味 |
|---|---|
| **規模** | 戦闘の大きさを選びます。切り替えると戦闘が最初からやり直しになります |
| **視点** | **どの立場から戦場を見るか**。ここが本作の中心です(下で詳しく) |
| **陣営** | 青軍から見るか、赤軍から見るか |

### 「視点」がこのゲームの肝です

同じ戦場でも、**どの階級から見るかで見えるものが変わります**。

| 視点 | 見えるもの |
|---|---|
| **分隊長** | 部下2個チームが今この瞬間に見ているもの。ほぼリアルタイム |
| **小隊長** | 部下の分隊長からの**無線報告だけ**。数秒古く、時間とともに不確かになる |
| **中隊長** | さらに小隊長経由。もっと古く、位置も曖昧 |
| **神視点** | 開発用。敵の本当の位置がそのまま見えます |

**「分隊長」と「小隊長」を交互に押してみてください。** 同じ戦場なのに、
小隊長には敵が少なく、位置もずれて見えるはずです。上に行くほど古い地図で
大部隊を捌くことになる — それがこのゲームの狙いです。

### 敵の表示

- **ひし形** = 報告された敵の位置。**今いる位置ではなく、最後に目撃された位置**です
- **薄い円** = 位置の不確かさ。時間が経つほど大きくなります
- **灰色のひし形** = 確度が尽きた情報。「昔ここに敵がいた」という記録だけ

### 兵士の色

| 色 | 状態 |
|---|---|
| 青 / 赤 | 健常 |
| 黄色 | 負傷(45秒以内に手当がないと戦死) |
| 緑 | 止血済み(後送待ち) |
| 水色 | 担架で搬送中、または搬送している隊員 |
| 灰色 | 戦死 |

### 地図上の記号

| 記号 | 意味 |
|---|---|
| **十字の丸** | 負傷者集合点(CCP)。担架班はここへ運びます |
| **大きなリング** | 争奪する拠点。色が所有陣営、内側の円が確保の進み具合 |
| **黄色いリング** | 係争中(敵味方が同じ拠点にいて、確保が止まっている) |
| **茶色の板** | 閉じた扉。突入班がこじ開けると緑になり、そこで初めて室内が見えます |

### 右上の数字

`BLUE 86/88 ▲3 ✚1` は「戦闘可能86名 / 生存88名、後送待ち3名、後送済み1名」です。

### 右のツリー(指揮階層)

**クリックすると、その指揮官をあなたが引き継ぎます。**
引き継いだ指揮官のAIだけが止まり、他は全員AIのまま動き続けます。
「観戦(全AI)」を押すと手を引いて観戦に戻ります。

操作中は、地図を**右クリック**するとその地点へ移動を命じられます。

> 重要な設計: **人間はAIの判断を置き換えるだけで、特別な力は得られません。**
> 見える情報も、出せる命令も、AIとまったく同じです。

### 下の操作

| 操作 | 動作 |
|---|---|
| ドラッグ | 地図を動かす |
| マウスホイール | 拡大・縮小 |
| **Space** | 一時停止 / 再開 |
| **.**(ピリオド) | 一時停止中に1コマだけ進める |
| ×1 のボタン | 速度切替(0.25〜4倍) |

## 4. まず何を見ると面白いか

1. **「小隊 vs 小隊」で「視点」を分隊長 ⇄ 小隊長で切り替える**
   → 情報が階層で減っていくのが分かります(本作の中心的な仕掛け)

2. **「市街地(CQB)」を選び、建物の扉に注目する**
   → 4名が扉の脇に一列に並び(スタック)、扉を開け、0.6秒間隔で1人ずつ突入し、
   部屋の四隅を確保します。米陸軍の教範どおりの手順です

3. **「中隊 vs 中隊」で右のツリーの「中隊長」を押す**
   → 91名の指揮官の立場になります。個々の撃ち合いには間に合わない、
   という感覚が狙いどおりかどうかを見てください

4. **誰かが負傷したら追いかける**
   → 隣の隊員が駆け寄って止血 → 分隊長が後送を判断 → 担架班2〜4名が編成され →
   CCPまで運び → 数分後に補充兵が合流、という流れが自動で走ります

## 6. 困ったとき

| 症状 | 対処 |
|---|---|
| `npm` は認識されていません | Node.js が入っていません。手順1へ |
| `Port 5173 is in use` | 前回の起動が残っています。表示された別の番号(5174など)で開けば動きます |
| 画面が真っ暗のまま | ブラウザを再読み込み(F5)。直らなければターミナルの赤い文字を確認 |
| 動きが重い | 「規模」を「小隊 vs 小隊」以下にするか、速度を×1に戻してください |
| 戦闘が終わらない | 拠点の過半数を45秒維持するか、片軍が全滅すると決着します。画面左下に勝敗が出ます |
