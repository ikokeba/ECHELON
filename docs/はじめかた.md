# はじめかた — ECHELON を動かす

このプロトタイプを画面で動かすまでの手順です。プログラミングの知識は要りません。
**Windows** を前提にしています。

---

## 1. 最初の1回だけ必要な準備

### Node.js を入れる

このプロトタイプは Node.js というソフトの上で動きます。入っているか分からない場合は、
そのまま次の手順に進んで確認できます。

1. <https://nodejs.org/> を開く
2. 大きく表示されている **LTS** と書かれたボタンからダウンロード
3. ダウンロードしたファイルを実行し、**すべて「次へ」で進めてインストール**

> すでに入っている場合は、インストーラーが「修復」などと表示します。そのまま閉じて構いません。

---

## 2. 毎回の起動手順

### ① ターミナルを開く

エクスプローラーで `ECHELON` フォルダを開き、
**アドレス欄(上のパスが出ている場所)をクリックして `powershell` と入力し、Enter**。

黒い(または青い)ウィンドウが開きます。これがターミナルです。
以降はここに文字を打ち込んで Enter を押します。

> うまくいかない場合: スタートメニューで「PowerShell」と検索して開き、
> 次の1行を打ってから Enter を押してください。
>
> ```
> cd ECHELON
> ```

### ② 部品を用意する(初回と、ファイルが更新されたときだけ)

```
npm install
```

数十秒〜数分かかります。大量の文字が流れますが、正常です。
最後に `added ... packages` のような表示が出れば完了です。

### ③ 起動する

```
npm run dev
```

数秒で、次のような表示が出ます。

```
  ➜  Local:   http://localhost:5173/
```

### ④ ブラウザで開く

表示された `http://localhost:5173/` を、ブラウザ(Chrome や Edge)のアドレス欄に
入力して開きます。**ターミナルのリンクを Ctrl キーを押しながらクリックしても開けます。**

戦闘が始まります。

### ⑤ 終わるとき

ターミナルで **Ctrl + C** を押します。「バッチ ジョブを終了しますか」と聞かれたら `Y` + Enter。

> ⚠️ ターミナルを閉じずに放置すると起動したままになります。次に `npm run dev` すると
> 「Port 5173 is in use」と出て別の番号(5174 など)で起動します。動作に支障はありませんが、
> 気になるときは一度 Ctrl + C で止めてください。

---

## 3. まず「作戦立案」から始まります

起動すると、いきなり戦闘が始まるのではなく**作戦を立てる画面**になります(画面左に
「作戦立案」のパネル、時計の横に「作戦立案中 — 時間は止まっています」と出ます)。

ここでやっていることは、**中隊長が地図に向かって攻め方を決めている**ところです。

- **主攻**(いちばん重要な拠点を取りにいく小隊)と**助攻**(その他)を1個ずつ決める
- どの小隊がどの拠点を取るかを割り当てる
- そこまでの**接近経路**を決める(地図に矢印と山形の印で出ます)

パネルの行にマウスを乗せると、その小隊の経路だけが濃くなります。

内容を読んだら **「▶ 戦闘開始」(または Enter キー)** を押してください。ここで初めて
時間が動き出します。

> **中隊長は敵がどこにいるか一切見ずにこれを決めています。** 戦闘前なので当たり前ですが、
> 実装上もそうなっていて、材料は地形と拠点と自軍の配置だけです。「敵がどこにいるか」ではなく
> 「どこを取るべきか」で組む、という実際の攻撃計画と同じ形にしてあります。
>
> 立案の画面だけは**敵の初期配置も見えます**(そこはまだ戦闘ではなく盤面の設定で、
> 敵の位置はあなた自身が置いたものなので)。戦闘開始と同時に、いつもの「見えているものしか
> 見えない」表示に戻ります。

拠点の位置を変えたければ「配置を変える (G)」から。置き直して適用すると、
**中隊長が作戦を立て直します**。

## 4. 画面の見かた

```
┌──────────────────────────────────────────────────────┐
│ 0:59 tick 1795   [⏸ 一時停止] [×1] [⏭ ステップ]       │  ← 時間の操作
│                                                       │
│ ┌──────────┐                          ┌────────────┐ │
│ │ 規模     │                          │ BLUE 86/88 │ │  ← 両軍の戦力
│ │ 視点     │        戦場               │ RED  85/87 │ │
│ │ 陣営     │                          ├────────────┤ │
│ └──────────┘                          │ 指揮階層    │ │  ← クリックで
│                                        │ 中隊長     │ │     指揮官交代
│ ┌──────────┐                          │  小隊長    │ │
│ │ 拠点     │                          │   分隊長   │ │
│ └──────────┘                          └────────────┘ │
└──────────────────────────────────────────────────────┘
```

### 左上のパネル

| 項目 | 意味 |
|---|---|
| **規模** | 戦闘の大きさを選びます。切り替えると戦闘が最初からやり直しになります |
| **視点** | **どの立場から戦場を見るか**。ここが本作の中心です(下で詳しく) |
| **陣営** | 青軍から見るか、赤軍から見るか |
| **配置** | 「初期配置・拠点を編集」で、両軍のスタート地点と拠点を自分で置けます(下で詳しく) |

### 「視点」がこのゲームの肝です

同じ戦場でも、**どの階級から見るかで見えるものが変わります**。

| 視点 | 見えるもの |
|---|---|
| **分隊長** | 部下2個チームが今この瞬間に見ているもの。ほぼリアルタイム |
| **小隊長** | 部下の分隊長からの**無線報告だけ**。数秒古く、時間とともに不確かになる |
| **中隊長** | さらに小隊長経由。もっと古く、位置も曖昧 |
| **神視点** | 開発用。敵の本当の位置がそのまま見えます |

**「分隊長」と「小隊長」を交互に押してみてください。** 同じ戦場なのに、
小隊長には敵が少なく、位置もずれて見えるはずです。上に行くほど古い地図で
大部隊を捌くことになる — それがこのゲームの狙いです。

### 敵の表示

- **ひし形** = 報告された敵の位置。**今いる位置ではなく、最後に目撃された位置**です
- **薄い円** = 位置の不確かさ。時間が経つほど大きくなります
- **灰色のひし形** = 確度が尽きた情報。「昔ここに敵がいた」という記録だけ

### 兵士の色

画面下中央に**凡例**が常に出ています(**L** キーで開閉)。以下と同じ内容です。

| 色 | 状態 |
|---|---|
| 青 / 赤 | 健常 |
| 白っぽく退色 | 制圧されている(撃たれて頭を下げている状態。命中率が大きく下がる) |
| 黄色 | 負傷(45秒以内に手当がないと戦死) |
| 緑 | 止血済み(後送待ち) |
| 水色 | 担架で搬送中、または搬送している隊員 |
| 灰色 | 戦死 |

### 地図上の記号

| 記号 | 意味 |
|---|---|
| **十字の丸** | 負傷者集合点(CCP)。担架班はここへ運びます |
| **大きなリング** | 争奪する拠点。色が所有陣営、内側の円が確保の進み具合 |
| **黄色いリング** | 係争中(敵味方が同じ拠点にいて、確保が止まっている) |
| **茶色の板** | 閉じた扉。突入班がこじ開けると薄くなり、そこで初めて室内が見えます |
| **緑のひし形** | 拠点の位置を示す標。地図を引いても大きさが変わらないので、遠くからでも見つかります |
| **白いリング** | いま操作しているユニット |
| **水色のリング** | クリックで選んだユニットと、その指揮下の隊員 |

### 右上の数字

`BLUE 86/88 ▲3 ✚1` は「戦闘可能86名 / 生存88名、後送待ち3名、後送済み1名」です。

### 右のツリー(指揮階層)

**クリックすると、その指揮官をあなたが引き継ぎます。**
引き継いだ指揮官のAIだけが止まり、他は全員AIのまま動き続けます。
「観戦(全AI)」を押すと手を引いて観戦に戻ります。

操作中は、地図を**右クリック**するとその地点へ移動を命じられます。

> 重要な設計: **人間はAIの判断を置き換えるだけで、特別な力は得られません。**
> 見える情報も、出せる命令も、AIとまったく同じです。

### 指揮官を選ぶと、その部下が光ります

地図上の**指揮官を左クリック**すると、その人の指揮下にある兵士全員に水色のリングが付き、
**直属の部下(中隊長なら小隊長、小隊長なら分隊長)へ線**が引かれます。
右のツリーのボタンを押したときも同じように光ります。

分隊長が倒れて次席が引き継いだ場合、光る範囲もそのまま新しい指揮官へ移ります。
「いま実際に誰が誰を指揮しているか」がそのまま見える、ということです。

### 初期配置と拠点を自分で決める

左上の「初期配置・拠点を編集」ボタン(または **G** キー)でパネルが開きます。

1. **道具を選ぶ** — 「BLUE展開」「RED展開」「拠点」のどれかを押す
2. **地図をクリック** — そこに置かれます。まだ戦闘には反映されません(予定の印が出るだけ)
3. **「この配置で立案する」** — その配置で盤面を組み直し、中隊長が作戦を立て直します

- 「正面」のスライダーで、その陣営がどちらを向いて展開するかを変えられます
- 拠点は**その上をクリックすると掴めます**。掴んだあと別の場所をクリックすると移動、
  何もない所をクリックすると新規追加です。`×` で削除、`r` が判定半径
- 地図上の**淡い印**が編集中の予定、**濃い緑のリング**がいま戦闘中の拠点です。
  「この配置で立案する」を押すまで置き換わらないので、両方が並んで見えます
- **「BLUEを点対称に写してRED」** — 青の配置をそのまま反転して赤に置きます
- 「既定の配置へ戻す」でシナリオ本来の配置に戻ります

パネル右上に「**点対称 / 非対称**」と出ます。既定の配置が点対称なのは、
**地形の有利不利が両軍でまったく同じになるようにするため**です。
自由に置くとこの対称は崩れますが、それは意図的にそうしたいこともあるので止めません
(両軍のAIが同じであることは変わりません)。片方が有利な状況を作って試すのも使い方のひとつです。

### 下の操作

| 操作 | 動作 |
|---|---|
| ドラッグ | 地図を動かす |
| マウスホイール | 拡大・縮小 |
| 左クリック | ユニットを選ぶ(配置の編集中は「置く」) |
| **Space** | 一時停止 / 再開 |
| **.**(ピリオド) | 一時停止中に1コマだけ進める |
| **H** | デバッグ表示のパネル |
| **G** | 初期配置・拠点のパネル |
| **L** | 凡例の開閉 |
| **Enter** | 作戦立案中に戦闘を開始 |
| **Esc** | 選択の解除(配置の編集中は道具を外す) |
| ×1 のボタン | 速度切替(0.25〜4倍) |

## 5. まず何を見ると面白いか

1. **「小隊 vs 小隊」で「視点」を分隊長 ⇄ 小隊長で切り替える**
   → 情報が階層で減っていくのが分かります(本作の中心的な仕掛け)

2. **「市街地(CQB)」を選び、建物の扉に注目する**
   → 4名が扉の脇に一列に並び(スタック)、扉を開け、0.6秒間隔で1人ずつ突入し、
   部屋の四隅を確保します。米陸軍の教範どおりの手順です

3. **「中隊 vs 中隊」で右のツリーの「中隊長」を押す**
   → 91名の指揮官の立場になります。個々の撃ち合いには間に合わない、
   という感覚が狙いどおりかどうかを見てください

4. **誰かが負傷したら追いかける**
   → 隣の隊員が駆け寄って止血 → 分隊長が後送を判断 → 担架班2〜4名が編成され →
   CCPまで運び → 数分後に補充兵が合流、という流れが自動で走ります

5. **建物に入った分隊を最後まで見届ける**
   → 廊下を取って終わりではなく、部屋を1つずつ潰していきます。全部屋を掃討して
   初めてその建物は「制圧済み」で、途中で放り出さないのが米陸軍の教範です

6. **指揮官を選んで、その部下がどこに散っているかを見る**
   → 小隊長を選ぶと麾下30名弱が光ります。前線がどれだけ広がっているか、
   どの分隊が離れすぎているかが一目で分かります

7. **接敵の瞬間を一時停止して見る**
   → 敵を見つけた分隊は、まず数秒かけて手近な遮蔽へ入りながら撃ちます
   (米陸軍の「React to Contact」)。そのあとで撃つ組と回り込む組に分かれます

8. **選抜射手(各分隊に1名)がどこにいるか探す**
   → 突撃には加わらず、後方の射線が通る位置から100m以上先を撃っています。
   一般兵の交戦距離は70〜80mなので、明らかに違う戦い方をしています

## 7. 困ったとき

| 症状 | 対処 |
|---|---|
| `npm` は認識されていません | Node.js が入っていません。手順1へ |
| `Port 5173 is in use` | 前回の起動が残っています。表示された別の番号(5174など)で開けば動きます |
| 画面が真っ暗のまま | ブラウザを再読み込み(F5)。直らなければターミナルの赤い文字を確認 |
| 動きが重い | 「規模」を「小隊 vs 小隊」以下にするか、速度を×1に戻してください |
| 戦闘が終わらない | 拠点の過半数を45秒維持するか、片軍が全滅すると決着します。画面左下に勝敗が出ます |
