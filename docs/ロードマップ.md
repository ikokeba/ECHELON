## 1. 新しい機能が守るべき設計原則

どの項目も、次の4つを崩さない形で設計する。崩れる案は、崩れない形に直すまで着手しない。

| # | 原則 | 仕様書 | 新機能での意味 |
|---|---|---|---|
| P1 | **情報の階層** | §5 | 新しい「目」(ドローン・車両・音など)が得た情報も、**見た者の記憶に入り、無線で遅れて上がる**。`world.soldiers` を直接読んで判断や照準に使わない |
| P2 | **両軍で同じ仕組み** | §2 / §13 | 陣営ラベルで分岐しない。変えてよいのは**編成(駒)と指揮の効き方(ドクトリン)**だけで、命中率や耐久への倍率で強さを作らない |
| P3 | **決定論** | §2 | 同じ初期条件なら同じ結果。乱数は陣営ごとのシード付き乱数列から引く。新しい設定は初期条件コード(`setupCode.ts`)に載せる |
| P4 | **人間・AI・LLM が同じ命令を通る** | §4 / `[v7.0]` | プレイヤー専用の機能は作らない。人間が使える機能は、**AIも同じ判断で使え、LLMも同じ命令で使える**こと |

## 5. 推奨する順番

```
(S-1〜S-5・S-1b は `[v7.2]`、A-6 以外の A 項目は `[v7.3]` で完了。迫撃砲の屋内判定は `[v7.4]`)
  S-6 ドローンの探知 → S-7 対ドローンの隠蔽行動
  → A-9 見え方の確率化 → A-10 撃墜 → A-11 操縦手の推定
  → A-6 LOD
  → B-3 電子戦 → B-2 自爆ドローン → B-1 装甲車
```

理由:

- **攻防戦の防衛側を厚くすると、それを崩す手段(発煙・対戦車火器・ドローン・迫撃砲)すべてに
  意味が生まれる。** 固定機銃(S-1、`[v7.2]` で実装)を起点にした
- 装甲車は見た目の効果は大きいが、経路探索と性能の両方に手を入れる必要があるので後ろに置く
- ドローンは §5 の書き換えを伴うので、下の設計メモの一線を確定させてから着手した(`[v7.3]`)。
  自爆ドローン(B-2)・電子戦(B-3)も同じ一線(見る者の記憶に入り、無線で遅れて上がる)に乗せる
- **`[v7.4]` 観測ドローンへの対抗手段を先に入れる。** プレイで「ドローンが強すぎる」と指摘された。
  原因は性能ではなく、**敵がドローンを認識する手段を持たない**こと(設計メモ §6.3)。
  B-2(自爆ドローン)を足すと非対称がさらに広がるので、その前に S-6 → S-7 で
  「見つけたら隠れる、隠れれば前進が止まる」という駆け引きを作る。どちらも既存の仕組み
  (音の接触・建物への移動・発煙)の組み合わせで済むので S とした
- B-3 を B-2 より前に置くのは、電子戦が観測ドローンだけで意味を持ち、§5 の仕組みに乗るから。
  B-2 は S-6・S-7・A-10 が揃っていないと一方的になる

## 6. 設計メモ

### 6.1 観測ドローン(A-2)— 旧 仕様書 §15 `[v6.9]` 案②(`[v7.3]` で下記のとおり実装。仕様書 §10)

**ドローンは §5(情報の階層化)にとって最大の脅威**。俯瞰の生映像を中隊長に与えると、
このゲームの中核である情報の階層化がその場で崩れる。したがって設計上の一線は明確で、
**ドローンは「見る主体」であって「全体像を配る装置」ではない**。

| 決めること | 案 |
|---|---|
| 情報の扱い | ドローンが見たものは**操縦手の記憶に入るだけ**。そこから先は分隊長と同じ扱いで、無線報告として遅延・減衰・粒度の低下を通って上がる。生の視界を上位へ直結させない |
| 視界 | 上から見るので壁に遮られない代わりに、**足元の範囲が狭い**(例: 半径40m)。盤面全体は見えない |
| 制約 | 飛べる時間が有限。操縦手は兵士なので撃たれるし、選抜射手と同じく優先目標になる |
| 面白さの核 | **中隊長の像だけが新しくなり、末端の像は古いまま**という、いつもと逆の勾配ができる。「見えているのに動かせない」という §5 の裏返しの体験 |
| ドクトリン差 | 自律群にドローンを持たせると「情報はあるが中央が動かせない」が成立する |

同じ節にあった案①(迫撃砲)は `[v6.10]` で実装済み(仕様書 §10「60mm迫撃砲による火力支援」)。

### 6.2 防衛計画フェーズ(S-1)— 論点(`[v7.2]` で下記のとおり実装。鉄条網も S-1b として実装)

- **置くのは誰か**: 防衛側の中隊長。人間が座っていれば人間、いなければAIが同じ候補から選ぶ(P4)
- **何を根拠に置くか**: 地形・拠点・自軍の配置だけ。攻撃側の配置は見ない(立案時の belief は空、P1)
- **数の上限**: 機関銃陣地は火器分隊の機関銃の数(小隊あたり2)まで。障害物は数か長さで上限を置く
- **攻撃側から見えるか**: 撃つまで見えない。撃てば通常の視認・報告に乗る
- **対称性**: 攻防モードはもともと左右非対称(仕様書 §12 `[v6.8]`)なので、ラベル入替の対称性テストには
  影響しない。ただし「防衛側どうしで陣営を入れ替えたら同じ陣地になる」ことはテストで固定する
- **初期条件コード**: 置いた陣地も初期条件の一部なので、コードに載せる(P3)


### 6.3 ドローンへの対抗(C-UAS)— S-6 / S-7 / A-9〜A-11 / B-2 / B-3 の整理(`[v7.4]` 時点)

#### 現状の分析: なぜ強すぎるのか

| 観点 | いまの実装 | 問題 |
|---|---|---|
| 探知 | 兵士の索敵(150m)にドローンは入らない | 見られていることを誰も知らない |
| 反応 | ドローンに対する行動が無い | 隠れる・止まる・撃つ、のどれも起きない |
| 被害 | 操縦手が倒れたときだけ落ちる | ドローンそのものは無敵 |
| キルチェーン | ドローンの接触 → 中隊長の像 → 迫撃砲(`pickTarget` は確度の高い塊を撃つ) | ドローンが見た塊はそのまま砲撃の目標になる |
| 屋内 | ドローンは屋根の下を見られない。**`[v7.4]` で迫撃砲も屋内では損害 ×0.15** | 以前は屋内に隠れても砲撃で同じように倒れていた |

強さの正体は「ドローンが見る → 迫撃砲が撃つ」の流れが**一方通行**であること。
観測ドローンの性能(視界40m・電池2本)を下げるのではなく、**相手の側に手を打たせる**方向で直す。

#### 実例とドクトリン

- **偵察ドローンに見つかると、地面に伏せて動かない**。ただし熱線カメラ・動きの分析ですぐ見破られ、
  効果は限られる(ウクライナ北部、2026年の報告)。→ A-9 で「伏せる」に効果を持たせるが、控えめにする
- **防御側は上空から部隊を見つけ、ドローンと迫撃砲で接近中に叩く。または入った建物を突き止めて
  封鎖し、破壊する**。→ S-7 で建物に入る代償として「入るところを見られたら接触が残る」を入れる。
  今の像の仕組み(最後に見た位置に接触が残る)でそのまま起きる
- **隠蔽・偽装・陣地の擬装(上からの見え方を含む)が基本**(豪陸軍がまとめたウクライナの教訓)
- **米陸軍 ATP 3-01.81(C-UAS)** は小部隊の対策を**受動的対策**(隠蔽・分散・移動の抑制)と
  **能動的対策**(射撃・妨害)に分ける。→ 受動 = S-7・A-9、能動 = A-10・B-3
- 小銃でドローンを撃つのは当たりにくく、自分の位置も晒す。→ A-10 で「撃てば銃声で知られる」を入れ、
  隠れるか撃つかの判断にする

参考: 豪陸軍 Cove「Countering unmanned aircraft systems — tips from Ukraine」、ArmyInform
「They lie on the ground and don't move」(2026-02)、militaeraktuell、米陸軍 ATP 3-01.81(2023)。

#### 一線(崩さないこと)

- **探知も「見た者の記憶に入り、無線で遅れて上がる」**(P1)。分隊がドローンに気づくのは、
  その分隊の誰かが見た・聞いたときだけ。中隊長が「敵のドローンが来ている」と知るのは報告の後
- **ドローンの接触は兵士の接触と混ぜない**。迫撃砲の `pickTarget` や擲弾の照準点に
  ドローンの接触を数えない(ドローンを砲撃しない)
- 両軍で同じ(P2)。対ドローン装備は編成の特技トグルで持たせ、命中率の陣営倍率では作らない
- 隠蔽行動は分隊への**命令**として作る。AIの分隊長も、人間も、LLM も同じ命令で出す(P4)

#### 項目ごとの論点

**S-6 探知**

- 距離: 目視は 80m 前後(視線が通ること。屋内からは窓越しのみ。煙の中は見えない)、
  音は 120m 前後で方角だけ。ドローンの視界(真下40m)より広いので、**先に気づくのは地上側**になる。
  プレイでの指摘「人の視界の方が広い」をそのまま形にする
- 接触の種類: 兵士の接触とは別の種類(`kind: "drone"` など)。定時・臨時報告に乗る
  (臨時報告の契機に「敵ドローンの探知」を足すかは要検討)
- 表示: 各座席の像に、ドローンの記号を確度つきで出す

**S-7 隠蔽行動(React to UAS)**

- 契機: 分隊の像に、新しい(例: 10秒以内)ドローンの接触が一定距離(例: 60m)内にある
- 行動の選び方(分隊長の判断):
  1. 25m 以内に建物 → 入って窓から離れ、ドローンが去るまで(例: 接触が20秒古くなるまで)待つ
  2. 建物が無い → その場で止まって伏せる(A-9 が入るまでは見た目だけの効果)
  3. 開けた場所を横断中 → 発煙(S-2)を焚いて渡り切る
- 例外: 突撃の最中・射撃壕や機関銃陣地に就いている防御側は続ける(陣地を捨てる方が危ない)
- 代償: 前進が止まる。入るところを見られた建物には接触が残り、中隊長の像に載る。
  屋内は迫撃砲に強い(`[v7.4]`)が、対戦車・対構造物火器(A-3)と突入には弱い — 隠れ場所が
  次の戦闘の場所になる
- 未決: 塹壕・射撃壕を「上からの遮蔽」に数えるか(屋根は無いが、破片は防ぐ)

**A-9 見え方の確率化**

- 動いている者は今と同じく確実に見る。止まっている者・伏せている者は毎秒の発見確率
  (例: 0.3/秒)で見つける。熱線があるので数秒で見つかる程度に留める
- 夜間(C-2)を入れるときは、熱線の有無でこの確率を変える

**A-10 撃墜**

- 小銃: 探知中かつ 60m 以内で低い確率(例: 0.02/秒)。対ドローン装備: 40m 以内で高い確率(例: 0.15/秒)
- AI の判断: 隠蔽行動を取っている分隊は撃たない(撃てば隠れた意味が無くなる)。
  陣地に就いている防御側・対ドローン装備の持ち主は撃つ
- 撃った銃声は A-5 の音の接触になる

**A-11 操縦手の推定**

- 戻っていくドローンを探知した兵士は、その進む方向に弱い接触(方角だけ)を作る
- 優先度は低め。S-6〜A-10 で駆け引きが成立するかを見てから判断する

**B-3 電子戦 / B-2 自爆ドローン**

- B-3: 中隊の資源。範囲内でドローンの操縦が切れる(戻る)、無線の遅延が伸びる。自軍にも掛かる
- B-2: S-6・S-7・A-10 と、屋内の遮蔽(`[v7.4]`)が揃ってから。対抗手段の無い状態で入れない

#### 検証の方法

- バランスのハーネス(`src/balance/`)に「ドローンの接触を起点にした迫撃砲の損害」の割合を足し、
  S-6・S-7 の前後で比べる。目安は、**ドローンを持つ側の勝率が上がりつつ、一方的にならない**こと
- 陣営ラベルを入れ替えた対称性テスト(P2)と、同じ初期条件での決定論(P3)を固定する
